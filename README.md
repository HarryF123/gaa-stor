-- GAA Stór -- 
A React GAA Statistics application -> Currently a prototype, maps Ireland using GeoJSON coordinates (sourced from GitHub, further augmented through the use of Claude to include the 6 northern counties). Upon clicking on any of the counties, the GAA pitches will be mapped on the zoomed section. These coordinates were sourced from the GAA Pitch Finder (gaapitchfinder.com) dataset. 

To be beautified. 

Will hopefully implement Java API background, for user creation, also statistics uploading. 
These club and player statistics and records are to be held in a PostgreSQL database.
